# JumpSaves

JumpSaves is a save file manipulation utility for [Jump Space](https://store.steampowered.com/app/1757300/Jump_Space/)
(the game).

JumpSaves is entirely free for any use. Our goal is to make your experience with JumpSaves better, but you should
understand that the software is provided as-is, with no warranty of any kind, and your should exercise reasonable
caution when editing your save files. If anything should go wrong, JumpSaves keeps plenty of automatic backups of
recent save state that you can restore as needed.

## Installing JumpSaves

Go to [JumpSaves Releases](https://github.com/gurudennis/JumpSaves/releases) and pick the most recent one at the top.

Then click on the JumpSavesSetup msi download link and install it. If Windows pops up a warning that says "Microsoft
Defender SmartScreen prevented an unrecognized app from starting", click on "More info" and then "Run anyway".

## Features

JumpSaves has two modes: "Transfer only" and "Cheater".

### "Transfer only" mode

In "Transfer only" mode, JumpSaves keeps track of what items you find while playing, and saves them to your
permanent collection it calls Library. This way you don't have to worry about losing an important item because you forgot to
add it to your exceedingly limited in-game item slots. At any time when the game is not running, you can copy items from your
library to your item slots or recent item list in the save, or vice versa.

We feel that expanding the list of items you can permanently keep in the game is only fair, especially a this stage in the
game's lifecycle when item rebalancing is frequent and impactful.

In this mode, you can also export your own items from the library to share with friends, and import theirs.

All of this we feel is sufficiently "light touch" and helps reduce the fear of missing out (FOMO) that plagues the Jump Space
experience today.

### "Cheater" mode

In "Cheater" mode, in addition to all the capabilities of the "Transfer only" mode, you can freely edit the contents of your
save in arbitrary ways. In particular, you can modify your resources (credits and ingots), as well as duplicate, create and
edit items and their modules (effects).

While doing so reduces the grind, we feel some users might object to having this much power, so you have to explicitly enable
this mode to use any of its features.
